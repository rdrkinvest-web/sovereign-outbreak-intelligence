Sovereign Outbreak Intelligence

Queries move. Sovereign data does not.

A federation of Ministry-of-Health agents investigates a possible cross-border outbreak together, while each country's patient-level data stays inside its own sovereign node. Built on Flower Agents: the coordinator runs on SuperGrid, and each country is a SuperNode in the federation @pbggo/east-africa-moh.

Who sits where

Each country's dataset is read only by its aggregate tools: deterministic functions that compute counts, rates, means and dates, apply that country's sharing policy, and audit their own output. The country's AI agent sits above the red wall. It decides which analyses to run and interprets the results, but it can only call those tools and read their aggregate results, never the rows. The coordinator sits one level further out on Flower's SuperGrid and only ever sees what the country agents send back.

One investigation, three rounds

Round 1. The coordinator asks every country the same question: is there unusual febrile illness in your border regions over the last 14 days compared with the previous 60? Each country's agent runs its local analyses and replies with aggregates plus a short interpretation. In the synthetic data, Kenya and Uganda each find fever up, platelets down and ALT up, with malaria unchanged. Tanzania stays near baseline.

Round 2. The coordinator compares the answers itself and finds the pattern shared by Kenya and Uganda. No messages are sent.

Round 3. The coordinator's AI picks one follow-up from a fixed menu (for example, “is the platelet drop concentrated among febrile patients?”), words it, explains why, and sends it only to Kenya and Uganda.

Result. A structured assessment for a human epidemiologist: supporting and contradictory evidence, uncertainties, and a recommended next step. It never declares an outbreak. It ends with a measured count: raw patient rows transferred: 0.

How the privacy wall holds

The agents reason freely, but privacy doesn't rely on them behaving. It's enforced by what they can reach and by code that checks everything before it leaves a country.

  1. The function list is the boundary. A country's AI can only call aggregate analysis tools. It has no file access and no ability to send messages itself. Adding a tool is a privacy decision.
  2. Code, not the AI, decides what crosses the border. The AI only proposes an answer. Code checks that every number it cites really came from a tool, that its yes/no matches what was computed, and that nothing row-shaped is in the reply. Only then does code send it; otherwise the country answers deterministically instead.
  3. Raw-data requests never reach the AI. “Give me the raw patient records” is refused by plain code, with a fixed refusal, before any model is involved.
  4. Even aggregates follow each country's rules. Small groups are suppressed and precision is limited, so a statistic can't point at an individual.

What crosses the border

InformationWhere it goes
Patient-level rowsNowhere. They stay on the country's own node.
Aggregates (rates, means, counts, dates)To the coordinator, and to the AI model provider when a country's agent reasons about them.
Questions and interpretationsBetween the coordinator and the country agents, and to the AI model provider.

Flower lets each node use its own model endpoint. A country that wants even its aggregates to stay home can point its agent at a model running on its own infrastructure, with no other change to the design.

The agents reason freely, but they can only touch data through audited aggregate functions, and code, not the AI, decides what crosses the border.

Synthetic demonstration data only. Anomaly strengths and confidence are demonstration scores, not validated epidemiological probabilities. This is a proof of architecture, not a public-health system.
